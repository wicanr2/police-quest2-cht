# 你不是來當英雄的：警察故事 2《復仇記》繁體中文化

![警察故事 2《復仇記》中文化](tools/assets/pq2-cht.png)

> **有些案件不是靠一把槍解決，而是靠你記得關門、帶齊裝備，並在正確的時候做正確的事。**

**Police Quest II: The Vengeance** 是 Sierra 的寫實警察辦案冒險遊戲。你扮演 Sonny Bonds，穿上制服、坐進巡邏車，從一份看似普通的勤務開始，逐步追查一名冷酷而狡猾的復仇者。本專案把 DOS SCI0/EGA 版完整帶入繁體中文：案件檔案、現場觀察、人物資料、通訊內容、文字指令、錯誤提示與失敗結局，都能用中文讀懂。

這不是把英文換成中文就結束的專案；它希望讓第一次接觸 Police Quest 的玩家知道：**你玩的不是警匪電影，而是一場會要求你遵守程序的警察勤務。**

## 先用一分鐘了解這款遊戲

### 你要追捕誰？

Lytton 市表面平靜，暗處卻有一名殺人不眨眼的冷面殺手。他躲在陰暗潮濕的角落，耐心等待下一個復仇目標；他犯案累累，行動沒有明顯規律，警方每慢一步，就可能再多一名受害者。Sonny Bonds 必須從零碎的案件資料、證物、通訊與嫌犯紀錄中，找出這名復仇者的下一步。

而最危險的轉折是：當你以為自己正在追捕獵人時，案件會突然讓你明白——**下一個目標可能就是你。**

### 你實際要做什麼？

每一段勤務都像一份可操作的警察報告。你要閱讀資料、駕車到現場、觀察環境、盤問相關人物、保管證物、正確使用裝備，再把結果回報給警局。遊戲不會因為你「大概知道答案」就放過程序；漏做一個步驟，可能扣分、失去證物、讓嫌犯逃走，甚至直接導向死亡結局。

如果你喜歡以下體驗，這款遊戲很適合你：

- 喜歡慢慢讀案件資料，從細節拼出真相。
- 喜歡老派文字冒險的自由輸入，而不是只按發光的互動物件。
- 喜歡「照規則玩」帶來的成就感，也能接受犯錯後重新來過。
- 想體驗 1980 年代 Sierra 對「警察工作」的想像，而不是扮演無敵的動作英雄。

### 夜半巷弄裡的復仇者

中文說明書的前言如此描寫這起案件：

> 夜半時分，有一位殺人不眨眼的冷面殺手，正潛伏在這條陰暗潮濕、到處堆滿垃圾的黑巷裡。他露出一對凶狠的目光，搜尋著下一個要報復攻擊的目標。這名罪犯早已犯案累累、殺人無數，即使再多殺一個人，也算不了什麼。
>
> 警探必須在最短的時間內，以最猛烈的手段，將這個殘暴、毫無人性的復仇者繩之以法。你得充分運用所有能想出的辦法，並接受各種模擬狀況的訓練，讓反應更加純熟敏捷。由於兇手的作案手法非常狡詐狠毒，你必須設法掌握他的下一個目標，好加以防範——然而，你作夢也想不到，下一個要遭到攻擊的目標，竟然是……**你！**

這不是單純的點擊尋寶遊戲。你扮演的是一名必須遵守程序的警察：觀察現場、調查證物、辨認嫌犯、正確使用裝備，並在緊張時刻做出合乎訓練的決定。遊戲會記住你的疏忽；錯過線索、忘記程序、遺失證物或在錯誤時機採取行動，都可能讓案件走向截然不同的結局。

### Sonny Bonds 的勤務日

本作延續 Sonny Bonds 的警察生涯。你會在警局、街道、機場、商場、海岸與下水道之間奔波，接受同僚指示，整理案件檔案，逐步拼起兇手留下的線索。每次出勤都不是「走到下一張地圖」那麼簡單，而是一串必須記住順序的勤務：先準備、再出發；先觀察、再行動；先控制現場、再處理證物。

遊戲的魅力在於「像警察一樣思考」：

- 先閱讀案件資料，再決定下一步行動。
- 依照警察程序處理交通、盤問、搜查與證物。
- 記住人物姓名、地點與細節，必要時回頭交叉比對。
- 善用 `look`、`ask`、`use`、`get` 等指令，讓文字冒險成為真正的辦案工具。
- 失敗並不只是 Game Over；每個錯誤結局都像一份反面教材，提醒你下次更謹慎。

簡單說，這是一款把「小心」變成遊戲機制的冒險遊戲。你會因為做對大事而前進，也會因為忘記一個小細節而付出代價；而當你終於按照程序完成一整段勤務時，那種成就感正是本作最獨特的地方。

## 下載與安裝

本專案採 **patch-only** 發佈，不包含 Sierra 原始遊戲資源、DOS 執行檔或 MT-32 ROM。請先準備自己合法取得的 `Police Quest II` DOS 遊戲資料，再使用下列其中一種方式：

### Windows

下載 `PQ2-CHT-win64.zip`，解壓縮後把原始遊戲檔案放入 `game/` 資料夾，再執行包內的 ScummVM。若已有自己的 ScummVM，也可以使用 `PQ2-CHT-win64-patch.zip` 中的中文資料與執行檔。

### Linux

下載 `PQ2-CHT-full-x86_64.AppImage` 或 `PQ2-CHT-patch-x86_64.AppImage`，加入執行權限後啟動：

```bash
chmod +x PQ2-CHT-*.AppImage
./PQ2-CHT-full-x86_64.AppImage
```

`full` 包含本專案可分發的引擎與中文資料，但仍需要玩家自行提供原始遊戲資料；`patch` 則只提供引擎與中文化檔案。

### macOS

下載 `PQ2-CHT-macos-universal.tar.gz` 或 `PQ2-CHT-macos-universal.dmg`。macOS 版本由 GitHub Actions 使用 `arm64 + x86_64` 合併編譯，Apple Silicon 與 Intel Mac 均可使用。

macOS 產物：[GitHub Actions build 30205123755](https://github.com/wicanr2/police-quest2-cht/actions/runs/30205123755)

## 原始碼與重建

公開中文資料位於 [`dist-cht/`](dist-cht/)：

- `translation.tsv`：繁體中文翻譯表
- `qfg1_big5.fnt`：SCI Big5 字型
- `qfg1_big5_hi.fnt`：高解析度 Big5 字型
- `pq2_title.ovl`：PQ2「復仇記」標題疊圖

重新產生翻譯資料：

```bash
bash tools/build_translation.sh
```

這會合併 `translation/full_skeleton.tsv` 與數字排序的 `translation/batch/*.tsv`，產生 `game/translation.tsv`、Big5 字型與 `game/pq2_title.ovl`。引擎 patch、Docker 驗收與三平台打包流程詳見 [`HANDOFF.md`](HANDOFF.md)、[`WORKLIST.md`](WORKLIST.md) 與 [`CONTEXT.md`](CONTEXT.md)。
